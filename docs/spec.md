# 🎣 Fishing Profit（釣果管理アプリ）製品仕様書 (Spec)

## 1. プロジェクト概要
Fishing Profitは、漁師や遊漁船運営者が日々の釣行における収支を管理し、純利益を可視化するためのモバイルファーストなWebアプリケーションです。

## 2. ユーザー体験 (UX) 仕様
### 2.1 画面構成（ボトムナビゲーション）
アプリは以下の3つの主要画面で構成され、画面下部のナビゲーションバーで切り替える。
- **ホーム (Home)**: 今日の収支サマリー、今月の累計統計。
- **入力 (Input)**: 釣行データの入力・編集。
- **履歴 (History)**: 過去の釣行記録のリスト表示。

### 2.2 日付ナビゲーション
- 「◀」「▶」ボタンによる1日前/1日後への移動。
- カレンダー形式（Date Picker）による任意の日付へのジャンプ。
- 表示されている日付に連動して、各画面のデータが更新される。

## 3. 機能仕様
### 3.1 データ入力
- **入力項目 (デフォルト値)**:
    - 乗船料金: 5,500円
    - 乗船人数: 5人
    - 燃料代: 10,000円
    - メモ (オプション)
- **リアルタイムプレビュー**: 入力中に「予想純利益（売上 - 燃料代）」をリアルタイムで表示。
- **保存機能**: 「保存」ボタン押下で、表示中の日付にデータを紐付けて保存。

### 3.2 統計・集計
- **当日の収支**: 選択中の日付の利益、売上、燃料代を表示。
- **月次統計**: 選択中の月（システム日付ベース）の「総純利益」「総売上」「合計釣行回数」を集計。
- **履歴リスト**: 最新10件の釣行履歴を表示。タップでその日の詳細（入力画面）へ遷移。

### 3.3 データ管理
- **永続化**: ブラウザの `localStorage` を使用。
- **データ構造**: 日付（YYYY-MM-DD）をキーとしたオブジェクト形式で保存。

## 4. デザイン仕様 (UI)
### 4.1 基本原則
- **モバイルファースト**: 最大幅 480px のコンテナ設計。
- **プレミアム感**:
    - 角丸（Border-radius: 12px以上）のカードUI。
    - ソフトなドロップシャドウ（Box-shadow）。
    - 洗練されたタイポグラフィ（システムフォント優先）。
- **カラーパレット**:
    - メイン: 深みのあるブルー（海をイメージ）。
    - 利益: 鮮やかなグリーン。
    - 損失: 落ち着いたレッド。
    - 背景: クリーンなオフホワイトまたはライトグレー。

### 4.2 モバイル最適化（親指操作エリア）
- **下段コントロール**:
    - 日付切り替え（◀ 日付 ▶）および「今日に戻る」ボタンは、スマホの片手操作を容易にするため、画面下部（ナビゲーションバーの直上）に配置する。
    - 日付表示タップでカレンダー（Date Picker）が起動すること。

## 5. 技術仕様
- **Framework**: React
- **Styling**: Vanilla CSS (Inline styles for rapid development and flexibility)
- **Deployment**: Render / GitHub Pages
- **Environment**: Node.js v18+
